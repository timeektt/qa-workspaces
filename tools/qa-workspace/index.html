Reject intakes ที่ค้าง

Jira · รอบติดตาม · สถานะดึงสดจาก Jira ทุกครั้ง

ติดตาม issue — เหลือใบไหนต้องแก้ให้เสร็จในรอบนี้

สร้าง “รอบ” พร้อมวันครบกำหนด แล้วค้นหาการ์ดที่ต้องแก้มาใส่ในรอบนั้น — ระบบจะดึงสถานะล่าสุดจาก Jira มาแยกให้ว่าใบไหนเสร็จแล้วและใบไหนยังเหลือ

วิธีใช้งาน — ติดตาม issue

หน้านี้แบ่งเป็น 3 ส่วนจากบนลงล่าง — แถบรอบ → ช่องค้นหา → รายการในรอบ

1 · แถบรอบ แถวบนสุด

  1. สร้างรอบใหม่ — กด ＋ รอบใหม่ เลือกวันครบกำหนด (ชื่อรอบไม่กรอกก็ได้ ระบบตั้งชื่อจากวันที่ให้)
  2. สลับรอบ — เก็บหลายรอบพร้อมกันได้ เลือกที่ช่อง รอบที่ติดตาม
  3. แก้ไข / ลบ — ✏️ แก้ไขรอบ แก้ชื่อกับวันครบกำหนด · 🗑 ลบรอบ ลบทั้งรอบพร้อมรายการข้างใน กู้คืนไม่ได้
  4. แถบสรุปใต้ปุ่ม — บอกวันครบกำหนด เหลืออีกกี่วัน และเสร็จไปกี่ใบจากทั้งหมด
  5. ป้ายมุมขวา — บอกว่าข้อมูลรอบเก็บไว้ที่ไหน ทีมเห็นด้วยหรือเปล่า (อ่านส่วนที่ 4)

2 · ช่องค้นหา Jira ตรงกลาง

  1. ค้นหา — พิมพ์เลขการ์ด, issue key หรือวาง url ระบบค้นให้เองไม่ต้องกดปุ่ม
  2. เพิ่มเข้ารอบ — กด ＋ เพิ่มเข้ารอบ ที่ผลลัพธ์ · การ์ดที่อยู่ในรอบแล้วปุ่มจะขึ้นว่า อยู่ในรอบแล้ว กดซ้ำไม่ได้
  3. ระหว่างบันทึก — การ์ดเด้งลงรายการทันที ขึ้นป้าย กำลังบันทึก… จนบันทึกเสร็จ ไม่ต้องนั่งรอ
  4. ถ้าบันทึกไม่สำเร็จจริง — ระบบถอนการ์ดที่เพิ่งเพิ่มออกเองพร้อมบอกสาเหตุ ไม่ทิ้งข้อมูลค้างที่ไม่ตรงกับของจริง

3 · รายการในรอบ ด้านล่าง

  1. สองกลุ่ม — พื้นเหลือง 🔧 ยังไม่เสร็จ · พื้นเขียว ✅ เสร็จแล้ว
  2. สถานะมาจาก Jira จริง — การ์ดที่สถานะอยู่ในหมวด Done ระบบย้ายไปกลุ่มเสร็จแล้วให้เอง ไม่ต้องติ๊กเอง
  3. อัปเดตอัตโนมัติ — ดึงสถานะใหม่ให้ทุก 2 นาที กด 🔄 รีเฟรชสถานะ ถ้าอยากได้เดี๋ยวนั้น
  4. ตัวเลขแดงบนหัวแท็บ — จำนวนใบที่ยังไม่เสร็จของรอบที่เลือกอยู่ เห็นได้โดยไม่ต้องเปิดแท็บนี้
  5. เอาการ์ดออก — 🗑 เอาออก เอาออกจากรอบนี้เท่านั้น ไม่ได้แตะการ์ดใน Jira

4 · ข้อมูลเก็บที่ไหน — ให้ทีมเห็นชุดเดียวกัน

ถ้าป้ายมุมขวาบนขึ้นว่า “🔗 เก็บบน Google Sheet” — เรียบร้อยแล้ว ทุกคนที่ตั้งค่าเหมือนกันเห็นและแก้รอบชุดเดียวกัน ต่างคนต่างเปิด server ของตัวเองได้ ไม่ต้องพึ่งเครื่องใครเครื่องหนึ่ง

ถ้าขึ้นว่า “💻 เก็บในเครื่องนี้เท่านั้น” — ยังไม่ได้ตั้งค่า คนอื่นจะไม่เห็นรอบที่เราสร้าง วิธีตั้ง: ใส่ 2 บรรทัดนี้ในไฟล์ .env แล้วปิด server เดิมเปิดใหม่

ROUNDS_SHEET_URL=<ลิงก์ Apps Script ที่ลงท้ายด้วย /exec>
ROUNDS_SHEET_TOKEN=<รหัสที่ตั้งไว้ในสคริปต์>

ขอค่าทั้งสองจากคนในทีมที่ตั้ง Google Sheet ไว้แล้ว · ถ้าจะตั้งใหม่ตั้งแต่ต้น ทำตาม tools/qa-workspace/apps-script/README.md

🔑 ค่าสองบรรทัดนี้เท่ากับกุญแจของข้อมูลรอบ — ใครได้ไปก็เพิ่ม แก้ และลบข้อมูลได้ทั้งหมด ส่งกันในแชททีมเท่านั้น อย่าโพสต์ที่สาธารณะและอย่า commit ลง git

5 · เปิดให้ทีมดูจากเครื่องเรา ทางเลือก

ตั้ง Google Sheet ตามส่วนที่ 4 แล้วไม่ต้องใช้วิธีนี้ — ให้เพื่อนเปิด server ของตัวเองก็เห็นข้อมูลเดียวกัน · ใช้วิธีนี้เมื่ออยากให้คนที่ไม่ได้ clone repo เปิดดูได้

แบบที่ 1 — ทีมอยู่ออฟฟิศ/วงเน็ตเดียวกัน ปิด server เดิมแล้วเปิดใหม่ด้วยคำสั่งนี้

SHARE=1 node tools/qa-workspace/server.js

หน้าต่าง terminal จะพิมพ์ลิงก์ http://<ไอพีเครื่องนี้>:3060/ ออกมา ส่งลิงก์นั้นให้ทีมเปิดได้เลย

แบบที่ 2 — ทีมทำงานนอกออฟฟิศ ใช้ port forwarding ของ VS Code ที่แท็บ PORTS forward พอร์ต 3060 แล้วตั้ง Visibility เป็น Organization (อย่าตั้ง Public เพราะใครมีลิงก์ก็เปิดได้) วิธีนี้ไม่ต้องใส่ SHARE=1

⚠️ หน้านี้ไม่มีระบบล็อกอิน ทุกคนที่เปิดลิงก์ได้จะเห็นข้อมูลทั้งหมด และอ่าน Jira ผ่านบัญชีที่ตั้งไว้ในเครื่องนี้ · เครื่องที่รัน server ต้องเปิดค้างไว้
